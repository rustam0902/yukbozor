# Инструкция по обновлению сайта Yukbozor на сервере UzCloud

## Что нужно для обновления:
- Доступ к серверу UzCloud через SSH (логин и пароль)
- Программа для подключения: PuTTY (Windows) или Terminal (Mac/Linux)

---

## ЭТАП 1: Резервное копирование базы данных

Это самый важный шаг! Если что-то пойдёт не так, вы сможете восстановить данные.

### 1.1 Подключитесь к серверу
Откройте PuTTY или Terminal и введите:
```
ssh root@198.163.207.109
```
Введите пароль когда попросит.

### 1.2 Создайте резервную копию
Скопируйте эту команду и вставьте в терминал (правой кнопкой мыши):
```
pg_dump -h localhost -U postgres yukbozor > /root/backup_before_tiyin.sql
```
Если спросит пароль базы данных - введите его.

### 1.3 Проверьте что файл создался
```
ls -la /root/backup_before_tiyin.sql
```
Должен показать файл с размером (не 0 байт).

✅ **Этап 1 завершён** - резервная копия создана

---

## ЭТАП 2: Миграция базы данных

Сейчас мы обновим структуру таблиц для поддержки копеек (тийнов).

### 2.1 Загрузите файл миграции на сервер
На вашем компьютере скачайте файл `migrate-tiyin.sql` из папки `uzcloud-update/`.

Затем загрузите его на сервер. В новом окне терминала (НЕ на сервере) выполните:
```
scp migrate-tiyin.sql root@198.163.207.109:/root/
```

### 2.2 Выполните миграцию
Вернитесь в окно с подключением к серверу и выполните:
```
psql -h localhost -U postgres -d yukbozor -f /root/migrate-tiyin.sql
```

Должны появиться строки "ALTER TABLE" - это означает успех.

✅ **Этап 2 завершён** - база данных обновлена

---

## ЭТАП 3: Обновление кода приложения

### 3.1 Перейдите в папку с сайтом
```
cd /var/www/yukbozor
```
(путь может отличаться - уточните где находится ваш сайт)

### 3.2 Скачайте последние изменения
```
git pull origin main
```
Если попросит логин/пароль GitHub - введите их.

### 3.3 Установите зависимости
```
npm install
```
Подождите пока завершится (может занять 1-2 минуты).

### 3.4 Соберите приложение
```
npm run build
```
Подождите пока завершится.

✅ **Этап 3 завершён** - код обновлён

---

## ЭТАП 4: Перезапуск приложения

### 4.1 Перезапустите сервис
Попробуйте одну из команд:
```
pm2 restart yukbozor
```
или
```
sudo systemctl restart yukbozor
```

### 4.2 Проверьте что сайт работает
Откройте в браузере: https://yukbozor.uz

### 4.3 Проверьте вход админа
1. Войдите с номером +998939698899
2. После входа должен открыться раздел "Админ панель"

✅ **Этап 4 завершён** - обновление завершено!

---

## Если что-то пошло не так

### Восстановление базы из резервной копии:
```
psql -h localhost -U postgres -d yukbozor < /root/backup_before_tiyin.sql
```

### Откат кода на предыдущую версию:
```
cd /var/www/yukbozor
git checkout HEAD~1
npm run build
pm2 restart yukbozor
```
