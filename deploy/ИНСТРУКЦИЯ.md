# Развёртывание Yukbozor.uz на UzCloud VPS

## Ваши данные сервера
- **IP адрес:** 198.163.207.93
- **Домен:** yukbozor.uz

---

## Шаг 1: Подключение к серверу

### Для Windows 10/11:

1. **Откройте PowerShell:**
   - Нажмите `Win + X`
   - Выберите "Windows PowerShell" или "Терминал"

2. **Подключитесь к серверу:**
   ```
   ssh root@198.163.207.93
   ```

3. **При первом подключении:**
   - Появится вопрос про fingerprint — напишите `yes` и нажмите Enter
   - Введите пароль от сервера (он не отображается при вводе — это нормально)

---

## Шаг 2: Установка системы на сервере

После подключения к серверу выполните эти команды:

### 2.1 Скачать скрипт установки:
```bash
wget https://raw.githubusercontent.com/YOUR_REPO/main/deploy/setup-server.sh
```

**ИЛИ** создайте файл вручную:
```bash
nano setup-server.sh
```
Скопируйте содержимое файла `setup-server.sh` и вставьте (правый клик мыши в терминале).
Сохраните: `Ctrl+O`, Enter, `Ctrl+X`

### 2.2 Запустить установку:
```bash
chmod +x setup-server.sh
./setup-server.sh
```

Дождитесь завершения (5-10 минут). Сохраните показанные пароли!

---

## Шаг 3: Загрузка проекта на сервер

### Способ A: Через Git (рекомендуется)

На сервере:
```bash
cd /var/www/yukbozor
git clone https://github.com/YOUR_REPO/yukbozor.git .
```

### Способ B: Загрузка ZIP файла

1. **В Replit:** Нажмите ⋮ → "Download as zip"
2. **Распакуйте** архив на компьютере
3. **Загрузите через SFTP** (программа WinSCP или FileZilla):
   - Сервер: 198.163.207.93
   - Логин: root
   - Пароль: ваш пароль
   - Путь: /var/www/yukbozor

---

## Шаг 4: Запуск приложения

На сервере выполните:

```bash
cd /var/www/yukbozor

# Установка зависимостей
npm install

# Сборка проекта
npm run build

# Миграция базы данных
npm run db:push --force

# Запуск приложения
pm2 start dist/index.js --name yukbozor
pm2 save
```

---

## Шаг 5: Настройка HTTPS (SSL сертификат)

```bash
certbot --nginx -d yukbozor.uz -d www.yukbozor.uz
```

При запросе введите email и согласитесь с условиями (Y).
