# Yukbozor - Мобильное приложение

Мобильное приложение для платформы грузоперевозок Yukbozor.uz

---

## 🚀 Как установить приложение на Android телефон

### Шаг 1: Создайте аккаунт Expo (бесплатно)

1. Откройте сайт: https://expo.dev/signup
2. Нажмите "Sign Up" 
3. Введите email и пароль
4. Подтвердите email (придёт письмо)

### Шаг 2: Скачайте проект на компьютер

1. В Replit нажмите на три точки ⋮ справа вверху
2. Выберите "Download as zip"
3. Распакуйте архив на компьютере

### Шаг 3: Установите Node.js (если ещё не установлен)

1. Откройте https://nodejs.org
2. Скачайте версию "LTS" (рекомендуемую)
3. Установите как обычную программу

### Шаг 4: Соберите APK

1. Откройте папку `mobile` в проекте
2. Откройте командную строку в этой папке:
   - **Windows:** Зажмите Shift + правый клик мыши → "Открыть окно PowerShell здесь"
   - **Mac:** Правый клик → "Новый терминал в папке"
3. Введите команды по очереди:

```
npm install
npx eas login
npx eas build --platform android --profile preview
```

4. При первом запуске вас попросят:
   - Войти в Expo аккаунт (логин/пароль)
   - Подтвердить создание проекта

5. Подождите 10-20 минут пока идёт сборка

### Шаг 5: Скачайте и установите APK

1. После сборки вы получите ссылку на скачивание APK
2. Откройте эту ссылку на телефоне
3. Скачайте файл
4. Откройте скачанный файл
5. Разрешите установку из неизвестных источников (телефон спросит)
6. Установите приложение

---

## ⚠️ Важно

- APK работает только на Android телефонах
- При первой установке телефон предупредит о "неизвестном источнике" - это нормально для приложений не из Play Store
- Приложение подключается к серверу Yukbozor для работы

---

## 📱 Возможности приложения

- **Вход и регистрация** по номеру телефона
- **PIN-код** для быстрого входа (4 цифры)
- **Отпечаток пальца** для ещё более быстрого входа
- **Заказы** - создание и просмотр заказов на перевозку
- **Сделки** - договоры и их статусы
- **Депозит** - управление балансом
- **Профиль** - настройки и выбор языка (русский/узбекский)

## 🔧 Для разработчиков

### Структура проекта

```
mobile/
├── src/
│   ├── components/     # Переиспользуемые компоненты
│   ├── screens/        # Экраны приложения
│   ├── navigation/     # Навигация
│   ├── context/        # React Context (Auth, Language)
│   ├── services/       # API сервисы
│   ├── constants/      # Константы (цвета, переводы)
│   └── utils/          # Вспомогательные функции
├── assets/             # Изображения и иконки
├── App.tsx             # Главный компонент
├── app.json            # Конфигурация Expo
├── eas.json            # Конфигурация сборки
└── package.json        # Зависимости
```

### Команды для разработки

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки (требует Expo Go на телефоне)
npm start

# Сборка APK для тестирования
npx eas build --platform android --profile preview

# Сборка AAB для Google Play
npx eas build --platform android --profile production
```

### Firebase / google-services.json

Файл `google-services.json` **не хранится в git** (добавлен в `.gitignore`).  
Для локального использования: скачайте его из [Firebase Console](https://console.firebase.google.com/) → проект `yukbozoruz` → Настройки проекта → Android-приложение → Скачать google-services.json. Поместите файл в `mobile/google-services.json`.

Для **EAS-сборки** файл передаётся как секретная переменная окружения `GOOGLE_SERVICES_JSON` (type: file, visibility: secret). Она уже настроена для всех окружений (production, preview, development) в EAS-проекте `@rustamuzb/yukbozor`. В `app.json` прописано `"googleServicesFile": "$GOOGLE_SERVICES_JSON"`.

Если переменная отсутствует в EAS — FCM push-уведомления на Android не будут работать. Пересоздать переменную можно командой:

```bash
npx eas env:create production --name GOOGLE_SERVICES_JSON --type file --visibility secret --value ./google-services.json
```

### Настройка API

Отредактируйте `src/constants/api.ts` для изменения адреса сервера:

```typescript
export const API_BASE_URL = 'https://your-server.com';
```
